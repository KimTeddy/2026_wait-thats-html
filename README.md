# Wait… That's HTML?!

[https://kimteddy.github.io/2026_wait-thats-html/](https://kimteddy.github.io/2026_wait-thats-html/)

Interactive browser experiments and simulations in single HTML files, featuring WebGPU, WebGL, and creative coding. No installation required.

AI-assisted creations with the models and prompts documented for each project. More experiments will be added over time.

## Experiments

### SINGULARITY · Black Hole Observatory

An interactive black hole visualization with real-time light bending and an accretion disk.

- Adjust gravitational lensing, disk rotation, and viewing angle.
- Rotate, zoom, freeze time, save snapshots, and enable ambient sound.
- Native WebGPU rendering with a WebGL2 fallback. No external libraries.

An artistic visualization, rather than a physically calibrated astrophysics simulation.

**Model:** OpenAI Codex, based on GPT-6.
